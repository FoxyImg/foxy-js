# JavaScript/TypeScript Packages and Apps
This monorepo contains packages and apps for working with [Foxy Image](https://github.com/foxyimg/foxy) image proxy.

## Packages

### `@foxyimg/url-builder`
A typescript/javascript package for building Foxy image URLs.

### `@foxyimg/vue-ui`
A Vue component library for building editing apps for Foxy presets.

### `@foxyimg/vue`
A package for using Foxy image URLs in Vue.js apps.  Should not be used for public facing apps.

## Apps

### `@foxyimg/preset-builder`
A Vue.js app for building Foxy presets.

### `@foxyimg/demo-app`
A Vue.js app for testing Foxy image URLs.
